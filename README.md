This repository details the statistical analysis done during Catherine's RaMP program 2025-2026.

It contains three main subfolders, each representing a different project:
2025_health_assessment_analysis: These scripts analyze the 2025 health assessment data collected at two sites in northwestern VT.
assoc_trees_analysis_cfd: These scripts are used to determine associations between the impact of neighboring trees around butternuts and those butternuts' health metrics.
land_management_analysis: These scripts investigate if land management and soil may contribute to butternut distribution and health metrics.
For more information on each of these projects, please check out their individual ReadMe documents with these folders.

No folder depends on the running of another to run; each project here is self contained and contains its own datasheets and scripts for analysis.
